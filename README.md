# UGATTA Website

合同会社UGATTAの公式サイトです。GitHub Pagesで公開します。

## 更新・デプロイ
GitHub Pages の **Deploy from a branch** を使い、`main` ブランチの `/ (root)` を公開します。`main` へ push すると自動的に反映されます。

```powershell
git add .
git commit -m "Update website"
git push
```
